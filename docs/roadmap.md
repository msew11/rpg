# 路线图

## 当前阶段：客户端基础纵切

- [x] 空白 Godot 4.7.2 .NET 项目、Windows 检查与导出工具。
- [x] JSON 配置、1000×1000 地图管理与可见区域呈现。
- [x] 模拟登录、角色选择、会话缓存。
- [x] 世界服务内的输入转换、Action 驱动 ECS、点击移动与模拟确认修正。
- [x] 基础 HUD、系统面板与系统/角色本地设置；面板关闭按钮统一位于标题栏右端。
- [x] 系统按钮上拉菜单：系统设置、返回角色选择、返回登陆、退出游戏；返回选角时清理角色数据与世界、保留账号会话，返回登录时释放账号会话。
- [x] 2D 等轴世界表现、点击坐标逆投影与 GM 设置文件定位面板。
- [x] 静态地图分块绘制与视口附近分块复用，消除移动期间的逐帧全量重绘。
- [x] 本地设置实例与修改流程收拢到 `SettingService`，设置数据类型按系统和角色拆分。
- [x] 地图配置文件、数据类型一一对应，由 `ConfigService` 持有已加载配置。
- [x] 地图工具通过 `ConfigService` 构建只读地图数据，界面通过服务读取地图配置。
- [x] 角色性别从会话数据接入玩家 entity；ECS 动作与逻辑朝向通过只读快照驱动男女基础身体的 13 个动作、八方向表现，点击移动接入跑步与站立。
- [x] NetService 与 protobuf 请求/响应/推送、进程内 MockServer、按角色 JSON 持久化；登录返回角色摘要，选角加载完整世界状态，纯协议数据类型以 Pb 结尾，接收后组装为独立 PbData，集中于 Session/Data 并内聚双向转换；协议按公共、登录、世界拆分；SessionService 在登录请求前创建并持有空 LoginCache 与 RoleCache，LoginCache 处理首份响应后认证，切角保留账号摘要并重置角色数据，Session 事件缓存优先并隔离旧会话消息。

- [x] `GameServices.Net` 全局服务入口、显式注册与所有权句柄；主场景统一推进和释放网络，账号会话绑定创建时的服务，保留显式网络请求队列测试，覆盖启动失败清理与场景重建。

- [x] 按功能聚合 Config、Setting、Net、Session、World、Animation 服务，统一 IService 契约；借鉴 Dalamud 的显式依赖和逆序卸载。Godot 节点通过 GameServices 调用业务，服务内部初始化状态，移除配置、设置、账号和动画的转发包装及独立输入转发类；设置状态与读写归 SettingService，账号缓存直接归 SessionService，世界协调归 WorldService，覆盖非法登录、切角设置隔离和部分释放失败清理。

- [x] 独立 EventBusService，由 GameServices 唯一创建并最后释放；网络显式绑定 EventBus，缓存与 UI 使用同一事件域，缓存通过全局入口订阅，移除 Net/Session 的事件转发与缓存事件传参；覆盖共享事件域、网络释放、错误报告及重启监听隔离。

- [x] 七个业务服务通过薄基类 Service 共享释放状态与检查，IService 暴露只读 IsDisposed；保持设置退出保存、网络异常清理和旧会话隔离，覆盖全部服务及清理失败后的状态。

- [x] ECS Component 统一为普通 sealed class，在类内部显式声明块体构造方法，初始化集中于构造方法；架构文档记录有参及无参组件的编写规范。

- [x] 地图拆分为纯数据组件与计算工具：DataMapComponent 仅保存只读地图数据，静态 MapUtils 统一处理裁剪与地图查询，移除 MapManager；覆盖快照隔离、越界输入、权威修正和地图边缘。

- [x] 无参 `GameServices.Initialize()`；环境服务集中持有配置、Schema、设置与模拟服务端目录，正式构造只声明前置服务依赖，按显式顺序初始化并逆依赖释放；隔离目录与传输保留在内部验收边界，覆盖构造失败与重启。

- [x] 全部八个正式服务集中在 `Initialize()` 方法体按依赖顺序创建；注册入口和所有权句柄只接收现成实例，隔离组装迁入测试目录。

- [x] 配置统一使用 Godot 资源读取，移除测试专用 System.IO 分支；配置和整组服务验收迁到 Godot headless，普通地图计算直接提供数据，通过统一测试命令运行全部既有用例。

- [x] 业务事件订阅限定于 CacheBase 实现类和 Godot UI：LoginCache 处理首次登录，MainController 显式调用世界初始化与权威同步，服务不持有协议监听；覆盖未认证选角拒绝、重试清理、订阅边界与 HUD 离树后的世界同步。

- [x] 服务仅通过构造获取前置依赖，禁止 GameServices 访问与循环/回填；按固定顺序创建并严格逆序释放。移除独立事件注册与静态引用，纯事件测试显式组装事件域，缓存测试注册完整服务组，覆盖全局入口撤销后的清理和网络提前释放。

- [x] 全部服务入口统一按完整注册访问，IsInitialized 仅表示注册存在，业务操作自行检查释放；Cache 不保存事件服务，订阅通过 GameServices.EventBus，释放只操作句柄，Session 仅绑定 Net。

- [x] 环境服务更名为 `Rpg.Config.EnvService`，脚本与 UID 迁入 `src/Config/`，全局入口与注册属性使用 `Env`，参数和局部变量使用 `env`，同步全部引用并保持生命周期。

- [x] 事件总线统一命名为 `EventBusService`，全局入口与注册属性使用 `EventBus`，参数和字段使用 `eventBus`、`_eventBus`；同步消费者与测试。

- [x] 男女默认头部及配套头发按身体逐帧挂接点合入全部 13 个动作，覆盖八方向；组合画布扩展与锚点同步平移，新增头部像素位置回归验收。

- [x] 角色协议统一归入 `role.proto`；选角列表创建/确认删除、空列表与重启持久化；创建页选择性别和全部 148 套头型并按 45° 顺逆旋转预览。头部与身体独立存储和分层绘制，共用身体帧、挂接点和镜像，头型贯通缓存、ECS、移动与存档，兼容旧存档默认头型。

- [x] 选角与创建页面改为中央可旋转预览、右侧列表或外观选项；选角预览与进入分离，列表下方创建、右下角返回登录；创建使用男女按钮和平铺头型，男女独立记忆头型/朝向/名字草稿，预览下方创建按钮弹出命名确认。

- [x] 移动性能诊断及地图分块合并绘制：Windows 图形模式可重复测量进入、静止和连续移动，保持原有画面、分块复用、移动和存档行为；秒级 Rider UI freeze 告警尚未复现，需要发生时的性能快照进一步归因。

- [x] GM 道具图鉴：将素材库全部 22,872 张物品图标与左右手武器首帧纳入项目资源，按四个来源分类显示，支持编号搜索、48 条分页、详情预览及小窗口浏览；穿戴规则仍待定。

- [x] 结合指定道具导出页面，默认按六父类型与原码子类型浏览全部21,792条具名道具；支持名称、ID、说明搜索，保留重复ID、477条缺图与分类推定信息，候选图标精确关联；原图片素材浏览独立保留，不引入装备玩法。

- [x] Normal 普通鼠标使用原配置热点；点地显示完整 circle 蓝色光圈，在 0.5 秒内由 25% 等比扩散到 125% 并淡出形成涟漪，覆盖连续点击、摄像机坐标、UI 输入隔离和离开世界清理。

- [x] 游戏启动应用保存的分辨率后，窗口在当前显示器居中；嵌入运行由引擎在宿主视口内居中。

- [x] 全新存档登录角色列表为空，只通过创建流程新增角色；缺失读取不补建演示角色，兼容已有角色与旧初始化标记。

- [x] 道具表 `item.json`、四字段 `ItemCfg` 与 ConfigService 按 ID 只读映射；启动校验、重复 ID 及文件诊断、释放后访问验收。初始表为空，后续记录按独立需求加入。

- [x] 统一单例/多例配置规范：config/ 根目录平铺纯配置 JSON，对象/数组分别由 SingleCfgCache 与 MultiCfgCache 加载；CfgFile 标注文件名，CfgKey 标注主键，ConfigService 持有 MapCfgCache 与 ItemCfgCache；迁移地图/道具及全部消费者，异常包含文件诊断，文档记录新增配置约定。

- [x] 加入 1012—1018 七件测试装备及 name 名称字段；确认武器大类1、防具大类2，七件小类沿用源编号，堆叠上限均为1；覆盖完整记录读取、空表与无效名称验收。

- [x] 基础背包与聊天 GM：basic.json 单例配置 8×5 格、角色增加行数默认 0；独立物品实例随角色原子保存，选角完整快照与背包变更推送；聊天 `/item <ID> [数量]` 发放当前角色道具，先补堆叠后占空格，空间不足全部失败；图标、数量及悬停名称，覆盖缺图、小窗口、输入隔离和重启持久化。

- [x] HUD 头像、技能栏、菜单与背包按内容收紧；默认聊天、首条技能栏和菜单底边齐平，自定义坐标继续生效，覆盖多视口、HUD 调整及小窗口背包滚动。

- [x] 背包原生拖放：空格整份移动、同类优先合并、其他占用格交换；按背包版本拒绝过期操作，服务端原子保存后刷新，覆盖取消、写盘失败、小窗口末格拖放、切角隔离和重启持久化。
