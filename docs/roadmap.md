# 开发路线（首版）

路线图表示建议的依赖顺序，不承诺日期。每个阶段在开始前拆成可验收的 OpenSpec change；状态随 change 的创建和完成更新。玩法与美术尚未确定，不在此预设。

| 阶段 | 状态 | 可观察的交付结果 |
| --- | --- | --- |
| 0. 项目方向与工具链 | 已完成；.NET 导出待验证 | 方向、架构和路线文档可查阅；Godot 4.7.2 .NET 无界面检查通过，C# 核心与世界 ECS 已接入；通用数据访问契约与测试已落在 main |
| 1. 等轴移动原型 | 已完成 | 固定测试地面中可 8 方向移动、镜头跟随；双键斜向沿瓦片轴、逻辑速度一致；玩家与世界状态由 ECS 类型组件承载，展示层读取组件与 System 计算结果 |
| 2. 连续世界区块 | 已完成；雷达读取优化已通过项目检查 | 手工测试区块可连续穿越并回环；仅显示附近 3 × 3 区块，地块改动在本次运行中保留；区块范围由无状态 ECS System 更新，雷达与完整地图已通过体验验收 |
| 3. 单人世界状态 | 已完成当前原型目标；会话私有仓库与五槽位本地存档已接入 | 玩家位置、朝向及已改变的测试地块能够保存、退出并恢复 |
| 4. RPG 核心循环 | 待定义 | 先确认具体玩法，再拆成独立的可玩功能增量 |
| 5. 联网架构验证 | 长期目标 | 在明确目标人数和服务器方案后，验证权威模拟、状态同步与区块归属 |

阶段 2 的手工区块和素材仅用于原型验收；地图最终采用手工制作还是程序生成，须在后续 change 中决定。阶段 5 不是当前单机版本的交付承诺。

本次世界 ECS 迁移保留了阶段 1、2 的验收行为。Windows 导出检查因本机缺少 Godot 4.7.2 .NET 导出模板而停在 preset 配置检查；安装匹配模板后仍需验证导出与启动。
