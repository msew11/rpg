# 开发路线（首版）

路线图表示建议的依赖顺序，不承诺日期。每个阶段在开始前拆成可验收的 OpenSpec change；状态随 change 的创建和完成更新。玩法与美术尚未确定，不在此预设。

| 阶段 | 状态 | 可观察的交付结果 |
| --- | --- | --- |
| 0. 项目方向与工具链 | 已完成 | 方向、架构和路线文档可查阅；Godot 检查与 Windows 导出通过；通用数据访问契约与测试已落在 main |
| 1. 等轴移动原型 | 已完成 | 固定测试地面中可 8 方向移动、镜头跟随；斜向速度一致，并验证 ECS 与展示层边界 |
| 2. 连续世界区块 | 待开始 | 穿越多个区块时无需切换主场景；远处区块卸载并重新加载，必要状态保持 |
| 3. 单人世界状态 | 待开始 | 玩家与已改变的世界状态能够保存、退出并恢复 |
| 4. RPG 核心循环 | 待定义 | 先确认具体玩法，再拆成独立的可玩功能增量 |
| 5. 联网架构验证 | 长期目标 | 在明确目标人数和服务器方案后，验证权威模拟、状态同步与区块归属 |

阶段 1 的地图内容可以使用占位资源；地图最终采用手工制作还是程序生成，须在地图功能的 change 中决定。阶段 5 不是当前单机版本的交付承诺。
