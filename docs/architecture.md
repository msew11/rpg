# 架构

项目使用 Godot 4.7.2、GDScript 和 2D 场景，启动入口为 `scenes/main.tscn`。目前 main 仅有项目初始场景与通用数据访问契约；具体玩法模块尚未定案。

## 数据访问边界

`scripts/data/data_source.gd` 是可注入的抽象数据源，定义按名称读取、更新与变化通知。它不持有数据，也不依赖场景树。调用方通过抽象契约访问数据，具体功能自行选择提供方和生命周期。详见 [数据层契约](data-layer.md)。

当前没有运行时存储实现。测试中的内存替身只用于契约验证；具体单机内存提供方将在 develop 的区块功能中决定。地图结构、坐标与玩法状态不属于 main 上的通用数据层。
