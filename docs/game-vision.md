# 游戏愿景

本项目的长期目标是基于 Godot 4.7.2 .NET 构建网络 RPG 客户端。客户端以配置和会话状态为数据来源，由引擎完成 2D 等轴世界与界面呈现；首个验收平台是 Windows 桌面。

当前阶段验证客户端架构、真实 TCP 与进程内独立服务器的 protobuf/Actor 边界。普通攻击已确定并实现；职业、技能、故事和美术风格仍待确定。现有协议覆盖演示登录、角色创建/删除、选角、头型外观、角色移动状态、背包与装备快照、主副手穿脱替换、道具移动、按数量丢弃与走近拾取、数值多地图身份、地图动态对象存储与九块 AOI，以及开发期 GM 发放；后续玩法能力须先有明确目标与验收场景，再进入对应 OpenSpec change。

首期纵切流程为：JSON 配置加载 → protobuf 模拟登录 → 建立账号会话与登录摘要缓存 → 角色列表管理与选头预览 → 角色选择并初始化角色缓存 → ECS 世界初始化 → 点击移动、服务端内存确认与定时落地及权威修正 → HUD 与本地设置 → 聊天 GM 发放、物品缓存与变更落地、角色装备窗口与双手持握、背包图标展示、拖放移动与数量丢弃、走近拾取与地面道具轮廓/Fetch 反馈。

默认入口已切换 TCP：登录时按服务器或纯客户端模式启动/连接，可信进入按需创建或加载角色三表。独立服务器20Hz权威移动、10Hz多人AOI推送，客户端预测和远端插值；地图、人物、HUD、背包装备可展示，已开放 GM 发放、背包整理、主副手穿脱及多人装备广播。开发账号为admin、demo1、demo2，密码123，服务器模式必须admin/123。地面丢弃、销毁与走近拾取已迁移，支持多人对象增删与共同落盘；正式认证留待后续实施，客户端与回归统一使用唯一正式协议和服务器。

怪物展示当前支持独立配置表与首条树妖：通过聊天 `/monster` 选择配置，回车进入鼠标缩影，左键地面确认后提交服务器创建，右键取消；已创建树妖沿用地图 AOI 与持久化。树妖使用完整通用基础属性并以100生命生成，受伤和死亡沿地图保存；怪物 AI、刷怪规则与后续属性投放保持待定。

怪物支持单目标选择与服务器普通攻击：左键点击可见像素选中、走近并持续攻击，右键怪物仅选中，右键空地取消。空手和全部现有武器使用各自范围、每秒攻击次数及整数点伤区间，法杖采用近战攻击2，飞刀直接命中。选中目标脚底循环红环，悬停显示红剑；服务器命中后即时多人跳字，生命归零移除，目标离开 AOI、换装或退出世界时取消攻击。尚不提供怪物 AI、血条、掉落、复活或死亡动画。
