# 游戏愿景

本项目的长期目标是基于 Godot 4.7.2 .NET 构建网络 RPG 客户端。客户端以配置和会话状态为数据来源，由引擎完成 2D 等轴世界与界面呈现；首个验收平台是 Windows 桌面。

当前阶段验证客户端架构、真实 TCP 与进程内独立服务器的 protobuf/Actor 边界。战斗、职业、故事和美术风格仍待确定。现有协议覆盖演示登录、角色创建/删除、选角、头型外观、角色移动状态、背包与装备快照、主副手穿脱替换、道具移动、按数量丢弃与走近拾取、数值多地图身份、地图动态对象存储与九块 AOI，以及开发期 GM 发放；后续玩法能力须先有明确目标与验收场景，再进入对应 OpenSpec change。

首期纵切流程为：JSON 配置加载 → protobuf 模拟登录 → 建立账号会话与登录摘要缓存 → 角色列表管理与选头预览 → 角色选择并初始化角色缓存 → ECS 世界初始化 → 点击移动、服务端内存确认与定时落地及权威修正 → HUD 与本地设置 → 聊天 GM 发放、物品缓存与变更落地、角色装备窗口与双手持握、背包图标展示、拖放移动与数量丢弃、走近拾取与地面道具轮廓/Fetch 反馈。

默认入口已切换 V2 TCP：登录时按服务器或纯客户端模式启动/连接，可信进入按需创建或加载角色三表。独立服务器20Hz权威移动、10Hz多人AOI推送，客户端预测和远端插值；地图、人物、HUD与只读背包装备可展示。开发账号为admin、demo1、demo2，密码123，服务器模式必须admin/123。物品、拾取、装备及GM写业务和正式认证留待后续迁移，旧链路由回归测试显式装配。
