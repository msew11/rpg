# 游戏方向（首版）

本文记录已确认的长期方向，不代表功能已经实现。当前实现状态以项目代码和 `openspec/specs/` 为准；具体增量由 `openspec/changes/` 记录。

## 已确认的目标

- 类型是等轴视角的 2D RPG，角色支持 8 方向移动。
- 第一阶段是单人玩法，玩家在一个连续的大世界中游玩。允许地图内容动态加载和卸载，但体验上不通过场景切换分割世界。
- 游戏逻辑采用 ECS；Godot 的场景和节点仍可用于显示、输入和工具编辑。当前原型使用 `main` 的自建 ECS 核心，长期实现选择仍随具体需求验证。
- 长期希望发展为 MMO。因此早期设计要减少单机逻辑与客户端画面的耦合，为以后由服务器管理世界状态保留边界；当前阶段不交付联网功能。
- 首个运行与验收平台是 Windows 桌面，项目使用 Godot 4.7.2 .NET 版；核心与世界模拟使用 C#，当前展示、输入和测试配置仍使用 GDScript。

## 当前状态

项目已有等轴移动原型：玩家八方向移动、跟随镜头，并可在可拖动的 GM 面板切换占位角色与两种 ErisEsra 像素素体，演示待机、行走、奔跑、攻击、交互、跳跃和转身素材；角色状态或模板变化会停止演示。玩家实体与移动已接入共享 ECS 核心。连续区块原型使用手工测试内容验证有限世界回环、按配置激活附近区块、卸载远处地块数据和重入恢复，雷达固定显示在左上角。启动界面可开始新游戏或从五个本地槽位读取进度；会话临时存档承接已卸载区块改动，玩家点击保存时合并活跃状态。游戏内 Chat 面板显示系统错误。当前素体及动作仅用于视觉原型；最终角色美术、战斗机制和联网尚未实现。

## 待决定

- RPG 的核心循环、战斗、任务、成长和经济系统。
- 美术风格、地图是手工制作还是程序生成，以及世界内容规模。
- 长期是否沿用当前自建 ECS 核心；更多 Godot 节点与 ECS 实体的具体映射。
- MMO 的玩家规模、世界分区方式、服务器技术栈及上线节奏。

这些选择须在对应功能的 OpenSpec change 中确认，不能由“未来 MMO”这一目标直接推定。
