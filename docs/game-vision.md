# 游戏愿景

本项目的长期目标是基于 Godot 4.7.2 .NET 构建网络 RPG 客户端。客户端以配置和会话状态为数据来源，由引擎完成 2D 等轴世界与界面呈现；首个验收平台是 Windows 桌面。

当前阶段验证客户端架构及进程内 MockServer 的 protobuf 消息边界，不确定战斗、职业、故事、美术风格或真实服务器连接方案。现有协议覆盖演示登录、选角和角色移动状态；后续玩法能力须先有明确目标与验收场景，再进入对应 OpenSpec change。

首期纵切流程为：JSON 配置加载 → protobuf 模拟登录 → 建立账号会话与登录摘要缓存 → 角色选择并初始化角色缓存 → ECS 世界初始化 → 点击移动、服务端确认落盘及权威修正 → HUD 与本地设置。
