# session-events Specification

## Purpose

定义会话内基于消息类型的监听契约，保证所有缓存处理完成后界面和世界才读取状态，同时明确注册、释放、重入以及异常行为，使调用顺序不依赖界面和缓存的创建顺序。
## Requirements
### Requirement: 缓存优先的类型监听
事件系统 SHALL 提供按具体类型注册的可释放监听，同一消息先执行全部缓存监听再执行普通监听；每阶段内按注册顺序执行。

#### Scenario: UI 先注册
- **WHEN** UI 在角色缓存之前监听相同响应或推送
- **THEN** UI 回调读取到该消息更新后的缓存

### Requirement: 监听生命周期与重入
事件系统 SHALL 对单条消息使用监听快照；分发期间新增监听仅处理后续消息，已释放监听不得再次执行。嵌套发布 SHALL 排队到当前消息所有阶段结束后执行；会话重置 SHALL 丢弃旧分发剩余监听及嵌套消息。

#### Scenario: 注册和取消
- **WHEN** 监听回调新增监听或释放尚未执行的监听
- **THEN** 新监听不参与当前消息，已释放监听跳过，后续消息使用更新后的监听集合

#### Scenario: 嵌套发布
- **WHEN** 缓存监听发布第二条消息
- **THEN** 第一条消息的普通监听先执行，第二条消息随后完整分发

### Requirement: 分阶段异常隔离
缓存监听失败 SHALL 报告错误并跳过该消息的普通阶段；普通监听失败 SHALL 报告错误并继续其他普通监听。失败不得阻止后续消息。

#### Scenario: 缓存异常
- **WHEN** 缓存处理响应时抛出异常
- **THEN** 普通监听不读取该消息的部分更新结果，后续消息仍可处理

#### Scenario: UI 异常
- **WHEN** 一个普通监听抛出异常
- **THEN** 其他普通监听仍被调用且错误可被观察

### Requirement: 唯一全局事件服务
客户端 SHALL 只由 GameServices 创建一个实现 IService 的 EventService，并以只读 Events 入口提供给网络、会话、缓存、世界和 UI；消费者 SHALL 不创建私有事件系统，不经网络或缓存构造参数逐层传递。事件服务 SHALL 在消费者之前就绪，整体退出时在所有消费者之后、环境服务之前释放；初始化前及释放后访问明确失败。监听异常 SHALL 通过 Events.Error 报告。

#### Scenario: 网络与缓存共享事件域
- **WHEN** 网络分发响应，缓存和 UI 通过 GameServices.Events 订阅
- **THEN** 所有监听使用同一个事件服务，缓存优先规则不变，额外网络实例不创建私有事件系统

#### Scenario: 网络释放和整体重建
- **WHEN** 一个网络实例释放，随后整体服务退出并重新启动
- **THEN** 单独释放网络不销毁事件服务；整体退出清除旧监听和待处理消息，新启动创建新的唯一事件服务，旧句柄不能释放新服务

### Requirement: 业务事件订阅边界
业务事件订阅 SHALL 只出现在 CacheBase 实现类和 Godot UI 类中；CacheBase SHALL 提供缓存阶段订阅与句柄托管机制。业务服务 SHALL 不注册协议监听、持有订阅句柄或通过回调包装间接订阅。网络服务 SHALL 继续负责发布解码消息和清理待处理消息。缓存 SHALL 在缓存阶段完成数据校验与更新，Godot UI SHALL 在普通阶段读取缓存并显式调用服务完成世界初始化或权威同步；服务 SHALL 继续拥有世界状态并通过 Action 写入 ECS。

#### Scenario: 首次登录缓存优先
- **WHEN** UI 先于登录缓存注册，随后发起登录并收到成功响应
- **THEN** 登录缓存先完成摘要校验与更新，UI 读取已认证状态；SessionService 没有登录订阅

#### Scenario: UI 协调世界初始化
- **WHEN** 当前角色选角响应成功且角色缓存初始化完成
- **THEN** Godot UI 显式调用世界服务建立地图、角色实体和角色设置后再创建表现，WorldService 没有选角订阅

#### Scenario: UI 协调权威同步
- **WHEN** 当前角色收到成功移动响应或有效状态推送
- **THEN** 缓存先更新快照，Godot UI 调用世界服务提交同步 Action，固定帧处理修正；HUD 是否存在不影响主控制器同步

#### Scenario: 非法缓存响应
- **WHEN** 登录摘要或角色状态校验失败
- **THEN** 错误通过事件服务报告并跳过普通阶段，不创建成功页面、世界或提交部分更新的同步 Action

#### Scenario: 释放与结构检查
- **WHEN** 检查正式代码订阅位置并退出、重建主场景
- **THEN** 除 CacheBase 的公共实现机制外，订阅调用只位于缓存实现类和 Godot UI 类；缓存与 UI 释放各自句柄，服务不残留监听，新场景不会收到旧回调
