# Proposal

## Why

项目目前只有占位启动场景，尚不能验证等轴视角、8 方向移动或 ECS 与展示层的边界。先做一个可运行的单人移动原型，才能在加入区块加载和更多玩法前检验这些基础决定。

## What Changes

- 在持续运行的主场景中呈现使用 CC0 素材的简易等轴地面、玩家和跟随镜头；具体素材包在实施前选定并记录来源。
- 支持 WASD 与方向键按屏幕方向进行连续 8 方向移动，斜向移动没有速度优势，并显示玩家朝向。
- 用自建最小 ECS 保存实体状态和执行移动模拟，Godot 节点只采集输入与呈现模拟结果。
- 更新架构文档与路线图，记录已确认的 ECS 方案和阶段进展。

本次不包含障碍碰撞、区块加载与状态恢复、存档、联网、战斗或最终美术风格。

## Capabilities

### New Capabilities

- `player-movement`: 单人玩家的屏幕方向输入、连续 8 方向移动和朝向反馈。
- `isometric-world-view`: 等轴地面、玩家投影和跟随镜头的可运行呈现。

### Modified Capabilities

无。当前没有已发布的能力 spec。

## Impact

替换现有占位主场景，新增 GDScript 模拟与展示代码、少量经确认的 CC0 视觉资源和相关检查；不引入 ECS 插件或服务端依赖。
