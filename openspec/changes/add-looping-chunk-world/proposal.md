# Proposal

## Why

当前地面是一次性绘制的有限测试场，无法验证连续世界中区块加载、回环坐标和区块状态保留。数据访问契约已经在 `main` 完成并合入 `develop`，现在可以用一个单人原型检验这些边界。

## What Changes

- 用手工配置的测试区块替换固定测试场，玩家跨区块移动时持续留在同一主场景。
- 有限数量的区块首尾相接；玩家可持续移动，逻辑地块坐标、区块坐标和回环后的数据 ID 保持对应。
- 只显示玩家附近的区块，远处区块卸载；区块状态按回环后的区块 ID 保留在本次运行的内存中。允许玩家切换脚下的测试地块，返回已卸载区块后改动仍在。
- 调试验收时可显示已加载区块的发光边缘，正常游玩时隐藏。
- 在视口左上角显示区块雷达，以描边区分当前加载的区块；玩家点和朝向固定在雷达中心，区块网格随玩家移动，供跨区块验收使用。
- 在左上角提供 Debug 面板，分别切换边缘线与雷达，并明确显示 F3 边缘线快捷键。
- 雷达补充当前区块坐标、完整黄色描边、灰色未加载区块和独立颜色的回环接缝；按 M 打开完整测试世界地图，支持鼠标左键拖动。
- 在 `develop` 中接入通用 `DataSource` 契约，区块逻辑和展示通过数据层交换状态；更新玩法文档和自动检查。

不包含退出游戏后的存档、联网、服务器权威状态、障碍碰撞、最终地图内容或美术风格。

## Capabilities

### New Capabilities

- `continuous-chunk-world`: 连续区块加载、首尾回环、内存状态保留及调试验收边缘。

### Modified Capabilities

无。现有等轴展示和玩家移动的可见行为保持不变。

## Impact

替换 `scripts/view/test_ground.gd` 所绘制的固定场地，在 `develop` 新增区块坐标、手工测试数据、单机内存提供方和视图管理代码；`main` 上的数据层抽象与文档保持通用。
