# Spec Delta

## Purpose

定义单人连续世界原型的区块加载、首尾回环与本次运行期间的状态保留行为，使玩家能够持续移动，同时让调试验收能够观察实际加载范围。

## ADDED Requirements

### Requirement: 连续的手工测试区块
系统 SHALL 在同一主场景中按玩家位置显示附近的手工配置区块，并在远处区块离开加载范围时停止显示它们。

#### Scenario: 穿越相邻区块
- **WHEN** 玩家从一个区块走入相邻区块
- **THEN** 地面连续呈现，玩家和镜头持续移动，主场景不切换

#### Scenario: 远离区块
- **WHEN** 玩家远离先前可见的区块
- **THEN** 该区块退出当前加载范围，当前显示的区块数量保持有界

### Requirement: 首尾回环
系统 SHALL 将有限数量区块的相对两侧相接，并使持续行走的位置与所读区块数据保持一致。

#### Scenario: 穿越世界边界
- **WHEN** 玩家从世界最右侧继续向右移动，或从最上侧继续向上移动
- **THEN** 画面与镜头不跳跃，并显示相对一侧的区块内容

#### Scenario: 负坐标与回环 ID
- **WHEN** 玩家移动到负地块坐标对应的区块
- **THEN** 系统读取与回环后规范区块 ID 相同的数据，地块在区块内的坐标保持正确

### Requirement: 本次运行内保留区块改动
系统 SHALL 在区块退出当前加载范围后保留玩家对其测试地块所做的改动，并在本次运行中重新加载该区块时显示改动。

#### Scenario: 返回已卸载区块
- **WHEN** 玩家切换一格地块，走远使该区块卸载，再返回
- **THEN** 被切换的地块仍显示改变后的状态

#### Scenario: 回环到同一区块
- **WHEN** 玩家完成一次世界回环后返回具有相同规范 ID 的区块
- **THEN** 对该区块做过的测试地块改动仍在

### Requirement: 调试验收边缘
系统 SHALL 仅在调试验收模式开启时显示当前加载区块的发光边缘，并允许关闭该显示。

#### Scenario: 打开调试边缘
- **WHEN** 调试者开启区块边缘显示并穿越区块边界
- **THEN** 发光边缘随当前加载区块出现和消失

#### Scenario: 正常游玩
- **WHEN** 调试边缘显示关闭
- **THEN** 地面上不显示区块边缘覆盖层
