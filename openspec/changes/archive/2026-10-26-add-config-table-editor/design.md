## 页面与数据

页面为单个无外部依赖的 HTML 文件，内置生成时的三个配置及 Schema 快照，确保通过 `file://` 打开时可立即查看。用户可使用文件选择器打开当前 JSON 和 Schema。支持 File System Access API 时保存回所选文件，否则下载新文件。

## 表格展开

Schema 的对象层级生成 `colspan` 分组表头；叶字段补足 `rowspan`。数组元素展开为多行，同一数据路径的父级值跨相邻行合并。编辑单元格始终写回原始 JSON 路径，不依赖显示行号。

## 编辑与校验

值编辑遵从字段类型；可添加或删除顶层记录和嵌套数组元素。字段结构操作遍历对应对象实例，同时修改 Schema 的 `properties` 和 `required`。原文 Schema 编辑处理高级约束。保存 JSON 前检查页面支持的常见 Schema 约束；Godot 启动校验仍是完整验收边界。

## 库选型

Tabulator 等网格库具备分组列及单元格编辑能力，但嵌套数组的真实行合并和 Schema 联动仍需自定义转换；本页规模有限，原生表格避免网络依赖及第三方许可约束。
