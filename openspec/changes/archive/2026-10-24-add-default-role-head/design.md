## Context

身体使用 A141/A142 的 26 套动画。原始 actcreate.lua 使用 head=1；head0101/head0151 分别为第一套男女头型，包含头发，每套五方向。DIMG 身体帧像素块后保存帧定位点、排序值及四个挂接点，首个挂接点用于头部；头部帧像素块后的定位点用于对齐脖颈。两者均相对裁剪块，必须分别加回裁剪偏移再组合。已通过五方向组合图核对。

## Goals / Non-Goals

目标：完整显示男女默认头部，随全部身体动作逐帧移动，镜像及脚下锚点稳定，运行不依赖外部目录。

不新增换装、外观数据、战斗或美术方向决定。

## Decisions

在导入时将五方向头部按每帧挂接点合成到身体透明帧，再复用现有图集导入。当前头型固定，合成使头身共用一个播放时钟，避免额外节点同步及缓存。扩大动作画布容纳所有头部边界，并对 Anchor 加相同平移，维持世界定位。源素材只读。

新增 Python 导入预处理，仅依赖 Pillow；校验 DIMG 头、帧数、块边界与挂接点。输出中间帧到被忽略的 build 目录；项目只提交最终图集、原生资源及来源记录。

## Risks / Trade-offs

- 挂接点解析错误会造成漂移：验证块间结构并渲染男女全部动作及方向，检查首末帧。
- 固定头型烘焙不支持运行时换装：当前需求仅默认头型，未来外观系统另行设计。
