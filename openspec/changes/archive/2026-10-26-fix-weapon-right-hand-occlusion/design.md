# Design

## Context

原身体像素块尾 +28 与 +36 是两只手的连接点。对照用户正背面截图及源画布，未镜像时 +28 是左手、+36 是右手。身体镜像后双手语义互换，只镜像整个组合会换手。旧测试只核对同一错误坐标，无法发现该问题。

## Goals / Non-Goals

**Goals:** 挂点跟随身体帧，持握右手不随八方向变化；正背面交叠像素符合截图要求。

**Non-Goals:** 不重画角色，不增加装备玩法或第二动画时钟。

## Decisions

- 导入 LeftHandAttachments / RightHandAttachments；未镜像选原右手，镜像选原左手，再由 Facing 镜像为实际右手。比固定偏移或只保留一只手能覆盖全动作。
- 新增 Facing/RightHand 挂点节点：位置为身体当前手部连接点减身体锚点，Weapon 子节点位置为负剑柄连接点，与头部相同的逐帧连接公式。
- 正背面固定为剑在前/身体在前；侧面按实际右手远近确定默认层次，原素材非零动作偏置随换手翻转。只调整挂点节点的兄弟顺序，不改变实体 Z 值。
- 对全部方向记录独立的实际右手黄金坐标；图形验收读取真实 SubViewport 的交叠像素，确认正面来自剑、背面来自身体，不再只核对节点层级或复制定位公式。

## Risks / Trade-offs

- 原素材只有五方向武器 → 继续复用同方向纹理，挂点选择抵消镜像的左右手互换。
- 非循环动作原有复用素材 → 保持现有策略，全部动作检查挂点同步；重点图形验收站立和跑步。
