## Context
现有角色固定为 1001/1002，登录摘要在 LoginCache 缓存阶段更新，世界通过 Action 接收权威快照。默认头部已离线合入动作。

## Goals / Non-Goals
**Goals:** 动态创建删除、全部头型选择、八方向预览和持久化外观，保留既有分层与回归场景。
**Non-Goals:** 真实认证、职业、战斗、装备或染色规则。

## Decisions
- 角色共享枚举、摘要、完整状态和选角/创建/删除放入 role.proto，world.proto 仅保留移动与推送，避免循环 import。字段追加 head_id；0 表示旧协议默认头部。
- 创建和删除响应返回完整摘要列表，LoginCache 原子转换后替换，普通 UI 监听只读取会话。请求期间禁止重复操作，切页隔离在途请求。
- 首次登录初始化演示存档，记录初始化标记。角色文件通过原子替换写入；删除使用持久化墓碑，列表和选角过滤墓碑，避免崩溃或重启复活，保留 ID 不复用。旧 JSON 缺失 HeadId 时默认为 1。
- 输入名字去首尾空白，限制 1 至 16 个字符并拒绝控制字符、重复名称；等级与初始属性沿用演示基础值，创建不直接进入世界。
- 导入全部 148 套头部五方向图集，额外导入无头身体与逐帧挂接点。AnimationService 按性别/头型/动作独立缓存，ActorView 按身体 FrameChanged 同步头部定位，两层共用镜像；避免离线复制 74 倍完整动作。组合不影响 ECS 时间与锚点。
- 预览独立于世界，屏幕八方向按按钮增减一个八分角，角色列表使用滚动区域，删除使用确认窗口。

## Risks / Trade-offs
- [存档写入失败] → 保留原文件，失败响应不更新缓存。
- [删除保留内部墓碑文件] → 文件仅供本地模拟服务端恢复与 ID 去重，不再允许选角；不清理本地角色设置。
- [独立图层挂接偏移] → 用原始挂接点及像素位置回归验收；导入数据随项目发布。

## Migration Plan
先迁移协议与新增字段，再更新持久化、缓存、ECS 和表现，最后接入 UI；旧存档保持兼容。以本地提交整体回滚，未推送。
