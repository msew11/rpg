# Spec Delta

## ADDED Requirements

### Requirement: 会话统一提交世界交互

运行中的游戏输入与调试操作 SHALL 经当前本地会话提交到世界，并向调用方提供既有事件结果。展示层 SHALL 仍可读取绘制所需世界状态；地图拖动与镜头显示参数 SHALL 只改变 UI 状态。

#### Scenario: 游戏快捷键

- **WHEN** 游玩中按空格或 F3
- **THEN** 当前会话分别提交玩家所在地块切换或区块边缘开关，既有视图与事件结果保持一致

#### Scenario: 调试面板操作

- **WHEN** 玩家在调试面板切换边缘线、雷达或请求创建测试怪物
- **THEN** 当前会话提交对应世界交互，面板与世界视图同步

#### Scenario: 恢复后的会话

- **WHEN** 玩家开始新游戏或读取存档并使用调试面板
- **THEN** 操作提交到当前会话的世界，不修改先前会话的世界

#### Scenario: 纯 UI 操作

- **WHEN** 玩家拖动完整地图或调整视野高度
- **THEN** 仅地图偏移或镜头参数变化，不提交世界事件
