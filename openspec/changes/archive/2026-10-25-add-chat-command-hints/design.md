## Context

ChatControl 当前有固定欢迎文字和占位提示，输入直接交给既有 GM 链路。服务端仅支持 item，配置表保存可发放的道具。

## Goals / Non-Goals

实现上下文候选、灰色数量提示、合法显式命令绿色反馈。保留默认数量及服务端权威校验，不添加命令或改变发放规则。

## Decisions

- 在 ChatControl 内用不抢焦点的 ItemList 展示候选，位于输入栏上方并限制于视口内；选择后补入文本，Tab 与上下键支持键盘操作，Escape 隐藏。
- 直接读取 Config.Item.Items，按 ID 排序和前缀过滤，不读取图鉴目录或引入新服务。
- 在 LineEdit 内覆盖不消费输入的灰色 Label，提示文字不进入实际文本；水平滚动、光标不在末尾或 IME 组合期间隐藏提示。
- 用与服务端一致的正 Int32 解析检查格式和配置 ID；仅显式提供数量时变绿。绿色不承诺背包容量或保存成功。

## Risks / Trade-offs

- 浮层可能遮挡记录或穿透世界 → 在视口内限高滚动，消费鼠标事件，以真实事件验收。
- UI 校验与服务端规则漂移 → 保持服务端不变，覆盖未知 ID、非正数、溢出、多余参数及恢复状态。
