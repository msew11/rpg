## Why

固定的聊天提示占用窗口空间，也无法在输入过程中帮助选择命令和道具。改为按当前输入提供候选与格式反馈。

## What Changes

- 移除聊天初始提示和输入框占位提示。
- 输入 `/` 展示命令候选，输入 `/item ` 展示配置中的道具 ID 与名称，支持点击和键盘补全。
- 有效道具 ID 后的空格显示灰色数量提示；显式输入有效数量后整行文字变绿。
- 保持数量省略默认为 1、服务端校验和聊天发送行为。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `gm-item`: 增加聊天命令的上下文提示和有效格式反馈。

## Impact

涉及 ChatControl、既有背包 GM 场景验收及架构与路线图；不改变协议、服务和服务端发放规则。
