## Context

GameHud 通过独立 CanvasLayer 显示 GM；外部库 item/item 与 item/itempic 共 12,709 张 PNG，avatar/weaponl 与 weaponr 共 10,163 张首帧预览。没有可靠的道具名称、职业或装备类型表；仅凭图片编号不能推断玩法分类。

## Goals / Non-Goals

**Goals:** 游戏内浏览全部上述素材，按来源确定的四类显示、支持搜索和分页、点击放大并查看来源编号。

**Non-Goals:** 不确定武器职业、属性、装备规则；不播放原始武器动画，不提供穿戴。

## Decisions

- 分类为道具小图标、道具大图、左手武器部件、右手武器部件，另提供全部。按来源分类可复现，不使用未证实的语义标签；大小图保留各自条目，避免错误去重。界面说明这些是素材预览及待定名称。
- Python/Pillow 导入四个目录全部 PNG，裁除透明边缘并以原始像素打包 2048 图集，目录保留来源、SHA256、尺寸、裁剪位置及图集区域。相较复制数万张独立 PNG，减少引擎导入文件数。正式运行只读 res://assets/items，不访问外部库。
- 独立 ItemCatalogControl 只拥有 UI 与静态素材快照，不增加业务服务。首次打开加载目录，每页最多 48 个图标；按页按需加载图集，原图预览保留比例。类别、搜索变化回第一页，空结果明确提示。
- 图鉴加入 HUD 面板互斥管理，右上关闭；相对视口调整大小，内容滚动，点击不穿透世界。关闭后可从 GM 再次打开。

## Risks / Trade-offs

- [缺失语义元数据] → 明示按素材来源分类，使用原编号，不臆造名称；后续有权威数据再细分。
- [左右手目录包含动作/方向变体] → 保留全部来源条目，展示首帧预览，不把条目数描述为独立武器数。
- [大量素材] → 图集与分页，避免创建上万节点；导入清单记录数量并验收覆盖、图集区域和实际按钮交互。
