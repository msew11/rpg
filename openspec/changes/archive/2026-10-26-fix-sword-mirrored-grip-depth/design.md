# Design

## Context

见 proposal.md。ActorView 已交换镜像前的身体挂点，但单手来源回退没有标明原画手别。剑类原画在握柄位置存在为原手形留出的透明缺口，移到另一只手后暴露；源右手跑步dir0的正负偏置又覆盖目标近手层次。

## Goals / Non-Goals

保留原画像素与实际主副手含义，修复跨手后的握柄连接及层次。独立左右手原画仍优先；不生成完整新武器姿态或改变世界排序。

## Decisions

- DataActorWeapon显式保存SourceRightHand。跨手回退使用目标farHand，原生同手继续使用源Layers，正背面既有规则保持。
- 剑与大剑导入时识别握点附近分离的刀身/护手与柄尾像素分量，以原画柄部颜色连接短缺口，输出独立GripFrames。仅补透明像素，不修改原始Frames，限制连接长度以避免误连装饰。
- GripFrames仅跨手显示，放在身体下面；原剑身保留目标层次，因此身体手形遮住补充握柄，腿不遮挡近手剑身。卸下同步清空，使用同一帧与连接点。
- 以真实GPU交叠像素和握柄缺口位置作回归，并重导完整624组审查包。原始2315帧黄金继续验证原画像素未被修改。

## Risks / Trade-offs

- [误连装饰] → 仅剑类、仅握点附近、仅两个分离分量间的短缺口，原像素不覆盖。
- [握柄盖住手掌] → 补充层固定在身体下方，GPU核验手部像素仍来自身体。
- [源层次变化影响双手素材] → 只在请求手别与原画手别不同且没有原生变体时启用回退规则。
