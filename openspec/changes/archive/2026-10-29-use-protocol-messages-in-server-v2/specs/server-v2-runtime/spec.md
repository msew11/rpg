## MODIFIED Requirements

### Requirement: V2 唯一分片与状态边界
V2 SHALL 按规范账号键、正整数角色 ID、正整数地图 ID 唯一创建分片，按需初始化；调用方 SHALL 通过消息引用访问 Actor，不取得其可写状态。跨单元消息 SHALL 只携带独立或不可变数据，不携带操作委托或业务上下文。请求独占的协议对象 SHALL 可直接进入邮箱并取得处理器返回的协议回复，无需中间数据类型；发送方入队后和处理器返回后 SHALL 分别移交请求与回复的使用权，不再修改对象。

#### Scenario: 并发取得分片
- **WHEN** 并发请求同一身份及其他身份的分片
- **THEN** 同一身份返回同一活动引用，独立分片可并行处理，未收到消息的分片不执行初始化

#### Scenario: 直接处理协议请求与回复
- **WHEN** 调用方通过消息引用发送请求独占的协议对象
- **THEN** 对应处理器接收原请求并返回协议回复，消息引用返回该回复；路由只负责身份定位和会话绑定元数据
