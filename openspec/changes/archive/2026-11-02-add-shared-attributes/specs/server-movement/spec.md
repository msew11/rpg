## ADDED Requirements

### Requirement: 按实体合并公开更新
世界帧 SHALL 对本人和其他角色复用 RoleWorldUpdatePb，远端同一角色的资料、状态、位置、装备变化合并为一条 updated_roles。分组缺失表示保持，出现表示整组替换。首次可见使用完整状态；全量与增量保持 oneof，完整验证后原子接纳。实际速度 SHALL 支持 double 小数，不截断为整数。

#### Scenario: 同角色多分组与多人批量
- **WHEN** 同一发布轮次内多个角色的位置、状态及装备变化
- **THEN** 每个观察者收到批量世界帧，各持续可见角色最多一条更新，相关分组一同接纳

#### Scenario: 空装备与缺口
- **WHEN** 装备组为空或世界帧出现序号缺口
- **THEN** 空装备组清空该远端装备，缺口按既有全量恢复且不覆盖本人私有属性
