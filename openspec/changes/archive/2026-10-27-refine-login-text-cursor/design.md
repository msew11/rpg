# Design

## Context
Edit 源画布为 9×15，Fetch 为 42×43；同样 1.25 倍缩放不能保证视觉大小相同。登录框目前是同一 VBox 的相邻子节点，默认分隔区域回落到 Arrow。

## Goals / Non-Goals
提高 Edit 可见度、消除两个登录框间的短暂手指，保留输入与现有布局。

## Decisions
- Edit 单独使用 32/15 缩放到约 19×32，热点同比例变化；普通和 Fetch 保持 1.25 倍。32 像素为本次默认选择，避免直接放大到超过输入框高度的 54 像素。
- 两个 LineEdit 放入独立 LoginFields VBox，保持与原外层相同的分隔距离，为容器指定 Ibeam；只让窄缝连续，不修改整个登录页面的鼠标。
- 引擎仍负责悬停和编辑，无逐帧切换、延时或额外输入状态。

## Risks / Trade-offs
- 无头模式看不到硬件像素 → 核对缩放与热点，并用真实视口输入回归连续悬停与编辑。
