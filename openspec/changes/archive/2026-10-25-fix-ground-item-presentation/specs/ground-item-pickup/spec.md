# Spec Delta

## MODIFIED Requirements

### Requirement: 物品轮廓高亮和 Fetch 鼠标
鼠标指向地面图标的完整显示矩形向外扩展 8 个逻辑像素的区域或名称 SHALL 高亮该物品图标的 alpha 外轮廓并切换 Fetch 开手，按下显示握手，移出复原。UI 遮挡、模态窗口、失焦、离开 AOI 和世界时 SHALL 清理反馈。不能用矩形边框代替物品轮廓，透明角落和扩展区域均可命中，超出扩展区域不命中；缺图占位也须可拾取。物品点击不得同时触发普通地图移动涟漪，背包拿起时原丢弃操作优先。

#### Scenario: 悬停与 UI 遮挡
- **WHEN** 指向物品、透明角落、扩展区域、区域外、其他 UI，或失焦与离开地图
- **THEN** 完整命中范围内显示轮廓及 Fetch，其他状态恢复原鼠标且无残留轮廓
