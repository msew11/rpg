# 物品素材预热验收记录

## 环境与口径

2026-10-26，Windows，Godot 4.7.2 .NET，Debug 构建。`tests/item_asset_smoke.tscn` 使用独立临时存档，角色携带六个背包物品和一件主手装备，共七种图标，全部属于同一图集。选角耗时涵盖同步模拟请求处理、资源准备及世界/HUD 创建；开包耗时只测 `Show()` 内可见性回调、格子创建和图标绑定，不等于完整帧耗时或输入到显示延迟。

## 测量

| 模式 | 版本 | 选角处理 | 首次开包 | 再次开包 |
| --- | --- | ---: | ---: | ---: |
| headless | 修改前 | 342.91 ms | 97.34 ms | 2.09 ms |
| headless | 修改后完整回归 | 325.70 ms | 5.20 ms | 1.92 ms |
| Windows / D3D12 Forward+ / RTX 5060 | 修改后 | 335.68 ms | 4.94 ms | 1.37 ms |

这些是同一验收场景的单次观测，受 JIT、文件和引擎缓存、硬件负载影响，不作为固定性能保证。优化后图形模式目录读取解析及索引共 100.38 ms，图集加载和裁剪资源准备共 58.61 ms，均发生在选角进入阶段。

## 检查结果

- `powershell -ExecutionPolicy Bypass -File tools/check.ps1 -Tests` 全部通过，包括编译、资源导入、主场景、.NET/Godot xUnit 及全部场景验收。
- 新增三个 Godot xUnit 用例覆盖空包不加载无关图集、同图集共享、后续按需补充、未知键/缺图占位、释放拒绝访问与新实例独立缓存。
- 新增真实选角与开包场景验证七个预热图标、仅一张图集、首次/再次开包不新增目录或纹理加载、空包切角不残留物品，以及主控制器退出后清空缓存。
- Windows 图形模式执行同一场景通过。
- 既有图鉴、装备、拖放移动、丢弃拾取、UI 边界及角色设置场景通过，四个生产消费者不再自行读取素材目录。

## 尚存限制

首次进入仍需同步读取目录和相关图集，成本移至进入阶段。进入后首次获得的新图标仍按需加载；全图鉴逐页浏览可逐渐持有更多图集，直到客户端服务释放。没有更改服务器角色存档、revision 或协议。
