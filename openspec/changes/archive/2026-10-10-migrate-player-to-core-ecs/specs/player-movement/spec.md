# Spec Delta

## Purpose

使当前玩家移动原型接入共享 ECS 运行时，并保持已验收的操作及展示行为。

## ADDED Requirements

### Requirement: 玩家状态由共享 ECS 管理

系统 SHALL 使用共享 ECS 实体 ID 和组件保存玩家位置、移动意图、速度与朝向，并通过已注册的 ECS 移动系统按固定步长更新玩家。

#### Scenario: 创建玩家

- **WHEN** 本地会话创建玩家
- **THEN** 玩家 ID 是有效的 ECS 实体，其初始位置、意图、速度和朝向组件均可读取，现有具名数据键返回相同的值

#### Scenario: 输入与更新

- **WHEN** 本地会话设置方向并推进一个固定步长
- **THEN** ECS 组件中的位置和朝向反映移动结果，具名数据键返回相同结果并对有效变化通知订阅方

#### Scenario: 视图重建与区块跟随

- **WHEN** 玩家移动后展示节点重建或穿越区块边界
- **THEN** 展示节点和区块逻辑仍从同一玩家状态读取位置与朝向，移动轨迹连续
