# Design

## Context

RolePreviewControl 共用于选角、创角和装备窗口，默认人物 2.4 倍并显示头像；地图 ActorView 为 1 倍。背包已提供完整的权威穿脱协议和跨窗口拿起状态，EquipmentSlotUtil 提供默认推荐槽。

## Goals / Non-Goals

目标是复用预览和物品请求流程，仅调整界面与快捷输入。不变更协议、存档、槽位规则、属性或战斗，也不改变选角创角的头像和比例。

## Decisions

- 为共享预览提供构造时配置的头像开关与人物比例，装备窗口使用隐藏头像、1 倍并收紧预览宽高；避免复制预览实现。
- 空槽标签放在槽内并忽略鼠标；有物品时隐藏标签，显示原图标，避免遮盖装备。
- Ctrl 状态从实际鼠标事件读取，优先于普通拿起放置，先取消旧拿起，再读取当前快照，调用既有 EquipItem。默认选槽复用 TryGetSlot，不新增拳刃选槽策略；右键只消费事件。
- 顺逆旋转用一对本地 SVG 箭头，所有共享预览复用同一按钮构建逻辑，按钮保留原测试名称和操作音效。

## Risks / Trade-offs

- 共享预览改动可能影响选角头像及旋转 → 默认配置保持原值，既有角色管理场景验证。
- Ctrl 快捷操作可能与拿起状态或世界输入冲突 → GUI 消费按下和松开，测试真实事件与版本变化。
- 卸下可能遇到满包 → 沿用服务端拒绝和既有错误反馈，新增实际输入回归。
