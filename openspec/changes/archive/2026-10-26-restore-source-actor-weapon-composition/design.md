# Design

## Context

问题与范围见proposal.md。只读原客户端静态证据及动作帧数见docs/source-actor-composition.md；当前代码跨手换图、比例采样、男女性别共表、反向层次与推测拆段均偏离来源。

## Goals / Non-Goals

**Goals:** 在表现层复原原客户端完整部件合成，保留身体唯一时钟与世界Y排序，用独立来源参考核对GPU。

**Non-Goals:** 不添加战斗语义、职业限制、装备属性或更换素材风格；不修改原客户端与art_export。

## Decisions

- 武器资源提供13个入口，SourceAction记录实际动作编号，AttackMotion记录原生攻击类别。原生动作完整导入，缺失入口引用站立纹理与锚点；不将攻击2/3别名到攻击1，也不按进度重采样。
- AnimationService按外观元数据解析身体攻击/准备类别，主手优先，空主手才取副手武器，盾牌不指定类别；空手保留请求。ActorView不修改ECS。换装实际动作改变时重新播放匹配身体，其他换装保留进度。
- DataActorComposition集中保存八方向四部件基础顺序，以及男女13动作×4部件×5方向×50帧的完整层次；层次按身体当前帧读取，不随武器站立回退丢失。ActorView对基础顺序做升序稳定排序，仅MoveChild改变角色内次序。
- 主副手固定使用各自源手与挂点，Facing容器整体镜像。删除RearFrames、GripFrames和跨手修复；武器源像素完全保留。
- 所有身体、头部和武器最近邻贴图关闭Godot的fix_alpha_border，避免自动改写低alpha来源颜色；黄金摘要校验全部RGBA。审查PNG将透明视口读回的预乘颜色转回直通alpha，避免浏览器重复乘alpha导致暗边。
- 最近邻AtlasTexture关闭filter_clip；该设置的UV边缘收缩会将最外一列采成邻列，完整GPU对照已定位女性大剑及枪施法的单像素回归。关闭后直接采样完整源区域，防止导入像素正确但GPU边缘失真。
- 独立参考工具直接读取原始DIMG、INI及原客户端常量，不调用生产导入器的排序/采样。全组合逐帧GPU审查包与参考合成比较，允许GPU混合量化产生的有限色差，但不允许几何、层次、帧、像素缺失的差异。关键争议帧另外放大人工复查。
- 审查清单区分请求动作、解析身体动作及各手实际SourceAction；仍覆盖全部13请求和允许槽位组合，重复类别如实标明。

## Risks / Trade-offs

- 原客户端静态分析不是游戏截图 → 记录二进制哈希和地址，独立来源合成与GPU比较，不声称运行原客户端取图。
- 旧测试错误固化跨手与拆段 → 保留身体、方向、独立运行与原像素验收，替换冲突断言为来源契约和最终画面对照。
- 站立回退可能与特定身体姿态不理想 → 如实沿用来源并标记回退，不补画或臆造新动作。

## Migration Plan

先重建项目内资源与元数据，再替换表现和验收，删除废弃派生资产，更新架构/路线图，运行完整检查与GPU审查，归档并保留中文本地提交。回滚使用该提交，无外部数据迁移。
