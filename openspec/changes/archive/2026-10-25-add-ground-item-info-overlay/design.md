## Context

`GroundItemsView` 将 `GroundItemCount` 放在物品世界节点下，始终显示 `×Count`。现有 `ItemNamePopup` 已提供不接收鼠标输入的名称样式。角色快捷键由 `RoleSetting`、`SettingService` 和 `GameHud` 管理。

## Design

- 地面节点只保留图标、轮廓和锚点；数量文字从世界节点移除。
- `GroundItemsView` 在高于世界、低于 HUD 的独立 CanvasLayer 中为当前 AOI 物品创建信息控件，单件只显示名称，多件显示名称和 `×N`。信息显示默认关闭，切换状态只属于当前世界会话。
- 信息控件悬停时高亮自身并联动物品轮廓和 Fetch 鼠标；左键在 UI 层消费点击，向主控制器发出物品 ID 并复用现有 `World.PickupItem` 调用。
- 每帧按图标的画布变换计算信息框候选位置，裁剪到视口范围，依稳定物品 ID 顺序寻找不与已放置信息框相交的空位；视口空间耗尽时隐藏无法无重叠安置的框。
- `GameHud` 复用已有按角色保存的快捷键流程，新增 `groundItems` 动作默认 Z，沿用文本输入、模态窗口、HUD 调整与重复按键隔离；通过事件通知世界表现切换。

## Acceptance

- 未按键时图标下没有 `×1` 或其他常驻数量，信息框隐藏。
- 按 Z 后当前 AOI 单件显示名称、多件显示名称与数量，再按 Z 隐藏；新进入和离开 AOI 的物品同步更新。
- 信息框在 UI 层、不被角色或物品遮挡；彼此不重叠，摄像机移动与视口变化后仍跟随并保持在可视区域。
- 信息框悬停高亮，点击可拾取对应物品，不触发普通地图移动。
- 快捷键可改绑且按角色保存，聊天输入、模态窗口与快捷键录入不触发切换。
