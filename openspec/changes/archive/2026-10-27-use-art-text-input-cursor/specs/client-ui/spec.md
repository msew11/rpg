# Spec Delta

## ADDED Requirements

### Requirement: 文本输入鼠标素材
客户端 SHALL 在登录账号、密码及其他使用文本 I 形鼠标的输入区域显示配套 Edit.gsa 首帧，随项目发布并记录来源。素材 SHALL 按 1.25 倍最近邻缩放，原始热点 (5,8) 同步缩放。悬停、点击与编辑 SHALL 保持原生输入行为；移出输入区域 SHALL 恢复当前位置对应的普通或 Fetch 鼠标，离开主场景 SHALL 清除自定义文本鼠标。

#### Scenario: 登录文本编辑
- **WHEN** 鼠标进入账号或密码输入框并点击、输入或选择文字
- **THEN** 显示 Edit 文本鼠标，输入与密码遮蔽行为保持正常

#### Scenario: 移出与生命周期
- **WHEN** 鼠标移出输入框、切换页面或退出主场景
- **THEN** 按实际悬停区域选择指针，不残留文本鼠标；退出主场景后恢复系统文本鼠标
