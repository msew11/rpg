# Design

## Context

`Main` 从本地会话读取玩家世界位置和朝向，`PlayerView` 当前只绘制占位角色。ErisEsra 素体提供 16×16 和 16×32 两种比例；实际精灵单元分别为 24×24 和 32×32。每个待机、行走精灵表有五行方向，左侧三个方向可水平镜像补齐八方向。

## Goals / Non-Goals

**Goals:** 让两种素体在等轴地图中按正确脚部锚点、方向和动作显示；保持模板选择为运行时显示设置。

**Non-Goals:** 战斗动作触发、角色定制、最终美术决定与存档格式变更。

## Decisions

- 只将运行中必需的待机和行走 PNG 精灵表复制到 `assets/player_templates/`，用来源文件记录作者及许可；保留下载目录中的完整原包供后续制作动作，不将 Aseprite 源文件或整个素材包当成项目资源再分发。
- `PlayerView` 保持为单个显示节点，使用子 `Sprite2D` 的区域裁剪播放精灵表。原有占位绘制保留为第三个选择，便于直接比较。
- 角色的脚部对齐 `PlayerView` 原点。方向由屏幕输入朝向决定：下、右下、右、右上、上对应五行；左侧镜像对应行。行走由当前有效移动输入驱动，停止时回到待机。
- `DebugPanel` 的选项框持有运行时选择，`Main` 接收变化并在视图重建时重新应用；不在 ECS 或正式存档增加视觉字段。

## Risks / Trade-offs

- [镜像方向与不对称服装] → 当前素体左右对称；后续设计非对称造型时需补绘左向帧。
- [受击与死亡动作尚缺] → 本次仅播放已有的待机和行走，不将未提供的动作标为已实现。
- [免费素材的署名条件] → 在项目来源文件记录作者、链接和许可；若免费游戏正式发布，还需在游戏可见署名中保留作者链接。
