## MODIFIED Requirements

### Requirement: 请求处理与 IO 分离

服务端 SHALL 通过 Actor 初始化加载所属摘要、角色或地图缓存，在 RUN 状态将消息路由到 Handler；Handler 只接收本次请求的内存上下文与请求并返回响应，只验证和修改内存，不执行文件、网络 IO，也不通过回调触发 IO。消息发送及信封版本、模拟时间推进、周期和关闭落地由 Actor 外层负责。角色、物品和装备扩展 SHALL 以平级实体缓存作为唯一业务状态。

#### Scenario: 离线缓存处理
- **WHEN** 所需摘要、角色和地图已加载，持久化目录不可访问
- **THEN** 登录、选角及合法物品操作仍能通过缓存处理并返回对应响应，发送和写盘仅发生在外层节点

#### Scenario: 拒绝操作保持状态
- **WHEN** 版本过期、背包不足或装备冲突导致请求被拒绝
- **THEN** 实体、摘要、编号、地图对象及待写标记保持原值，不产生成功通知

#### Scenario: 等待中的请求
- **WHEN** 合法移动或远处拾取进入等待
- **THEN** 外层推进时间后发送最终响应，保留移动延迟、走近拾取、重复请求和取消行为
