## Context

RepoServerRole 在 List 初始化和 Load 缺失文件时生成演示角色，Create 也借用演示角色模板。已有测试大量依赖这两个角色。

## Goals / Non-Goals

**Goals:** 全新存档为空；只能显式创建；兼容旧存档；保留创建角色既有属性和男女坐标。

**Non-Goals:** 注册、多账号、清理已有演示角色、调整出生位置和角色属性。

## Decisions

- 删除演示角色常量、模板与 initialized 标记管理。List 只确保目录存在，Load 缺失时报错；旧标记作为无关文件忽略。
- Create 直接构造 DataServerRole，编号继续从 1003 起，保留墓碑参与递增及原有男女坐标。
- 测试使用专用已有存档数据准备工具，显式选择需要的测试数据。角色管理 UI 从空列表完成首次创建。

## Risks / Trade-offs

- [大量旧测试依赖默认角色] → 显式准备已有存档并运行完整测试。
- [误删已有角色] → 不清理存档，增加无标记旧目录与旧标记兼容测试。
