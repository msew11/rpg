# Design

## Context
沿用现有20Hz权威时钟、10Hz地图帧和Login→Role→World单向调用。已确认产品决策见proposal及specs。

## Goals / Non-Goals
完整实现空手、武器和树妖普通攻击。法杖近战；不增加AI、弹道、血条或掉落。

## Decisions
- 属性编号4保留不用，7/8为下限/上限，9为范围，10为攻速；通用map仍为double，点伤强制整数。
- 范围/攻速由主手替换等级基础值，点伤相加；装备内容变化使正常属性失效。
- 客户端负责预测走近和每次起手，Role记录不可变攻击快照、命中截止和下次攻击时间。移动与取消立即入队；World串行扣血，Actor不反向调用。
- 起手、取消、命中通过地图事件队列与观察者快照即时投递；不占世界帧序号。客户端版本覆盖层合并即时血量和死亡墓碑，防止旧世界帧倒灌。
- 时序配置记录性别/动作的原时长与命中比例，整体缩放到1000/攻速；空手攻击1。
- 旧怪物缺血量时在加载业务边界初始化满血并标脏，新增血量由共同保存链路落盘。

## Risks / Trade-offs
- 取消晚于权威命中到达 → 保留已发生伤害，以攻击编号及时间校正表现。
- 20Hz时钟存在至多一轮量化 → 命中即时发布，不额外等待10Hz。

## Migration Plan
客户端、服务器与配置同包更新；旧编号不复用，旧怪物补血量，回滚通过本地提交。
