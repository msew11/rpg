## Context

`scenes/main.tscn` 当前直接进入游戏。`LocalSession` 创建独立的 ECS 世界与固定测试区块，玩家位置、朝向和地块内容可通过 `WorldState` 读取；尚无跨运行持久化。

## Goals / Non-Goals

**Goals:** 标题页开始与读取入口；五个独立存档槽；游戏内保存；恢复玩家位置、朝向和已修改的测试地块；无效存档安全失败。

**Non-Goals:** 自动保存、云存档、地图格式迁移、最终 UI 美术和完整 ECS 通用序列化。

## Decisions

- `main.tscn` 仍是唯一启动入口。全屏标题遮罩与游戏内按钮由其 UI 层呈现；切换会话时重新绑定视图，游戏世界仍保持连续场景。
- `SaveSlots` 将五个版本化 JSON 文件保存在 `user://saves/`。每个文件记录保存时间、玩家连续位置与朝向，以及相对当前手工测试地图发生变化的规范区块地块数组。
- 读取前完整验证版本、字段、坐标、朝向、区块边界、地块长度和取值；在新建会话上恢复，成功后再切换主界面引用。空槽位和无效槽位分别标识。
- 保存覆盖所选槽位；不清理其他槽位。用户可从游戏返回标题，再读取任一有效槽位。

## Risks / Trade-offs

存档绑定当前手工测试地图尺寸和地块类型。地图结构变化时旧档可被判为不兼容；暂不设计迁移。保存范围仅包含目前玩家能修改的持久状态，调试开关与地图拖动偏移不属于进度。
