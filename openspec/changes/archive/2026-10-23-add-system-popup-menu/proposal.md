# Proposal

## Why

当前“系统”按钮直接打开设置，缺少统一的退出和返回入口。用户要求点击后向上展开包含四个指定条目的菜单。

## What Changes

- 点击“系统”向上展开菜单，按从上到下顺序显示“系统设置、退出游戏、返回登录、返回角色选择”。
- 系统设置打开现有设置面板；退出游戏关闭客户端；返回入口清理当前世界与会话，进入相应页面。
- 选择条目、点击菜单外部或按 Esc 后收起菜单，菜单交互不触发世界移动。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `client-ui`：调整系统按钮行为，增加上拉菜单及四项操作的验收场景。

## Impact

修改 `GameHud` 和 `MainController`，扩展 Godot 场景集成测试并更新路线图。复用现有设置和会话清理能力，不新增依赖、玩法或认证协议。
