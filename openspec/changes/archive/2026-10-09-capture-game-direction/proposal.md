# Proposal

## Why

项目已明确等轴视角、8 方向移动、无场景切换的大世界、ECS，以及单机先行并以 MMO 为长期目标，但这些决定仍散落在对话中。后续 agent 需要可查阅的共同背景，同时不能把尚未确定的实现方案当成既定需求。

## What Changes

- 建立项目愿景、架构边界和开发路线三份长期文档，分别记录目标、设计约束与阶段顺序。
- 在 `AGENTS.md` 和 `README.md` 中标明文档入口及更新规则。
- 明确已确认、建议采用和待决定的内容，避免未来目标被误写为当前功能。

## Capabilities

### New Capabilities

无。本次只记录项目方向，不增加游戏行为。

### Modified Capabilities

无。

## Impact

仅影响项目文档和 agent 工作约定；不修改场景、脚本、资源或导出行为。
