| 风险 | 覆盖 |

| 未知地图、缺失清单 | 未知地图不调用仓库；空地图及恢复原值不创建存档目录 |
| INIT 故障修复 | 清单/块损坏、根 null、缺块和真实文件独占锁；失败不进入 Handler，修复后目录返回新分片 |
| 内容比较 | 独立同内容数组不脏，默认数组为空，跨块移动两端待写，反复移动合并最终差异，恢复基线取消待写 |
| 逐块与空地图恢复 | 未变块文件字节与时间戳保留，移动来源引用移除，末对象删除及清空地图可重启恢复 |
| 提交中断 | 候选全部落地、清单提交前注入中断；重载完整旧状态，成功重试后完整新状态，孤立候选不加载 |

| 不引入对象业务校验 | 重复空 GUID、负版本/数量/编号、负坐标及地图外坐标、混合载荷均可独立读写 |
| 邮箱与失败重试 | 本地图保存阻塞期间后续回合等待，其他地图继续；保存失败保留快照及脏块，修复后重试 |
| 调度和关闭 | Role 完成后地图组并行，地图完成后 Login；单地图失败不短路其他地图和账号；周期禁用、动态间隔、轮次合并、周期失败重试、显式/关闭屏障及最终保存失败仍停止资源 |

## 边界

全地图对象常驻内存，Commit 按全量分组比较，块内顺序参与内容比较；仓库依赖同地图 Actor 串行调用，不支持多进程写者协调。本次只实现 World 数据加载与写回，不增加 AOI、怪物行为、拾取、正式业务协议、创角、首次入角或跨 Actor 事务，不修改 Actor 通信机制。旧客户端链路保持运行，V2 默认登录仍返回未实现；所有 V2 数据隔离在 v2 子目录，不读取或迁移旧存档。
