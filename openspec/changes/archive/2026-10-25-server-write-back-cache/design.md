## Context
现有 RepoServerRole 已提供分域 JSON、回滚及原子替换；MockServer 每次操作直接调用它。
## Goals / Non-Goals
目标为请求只更新内存、按检测节点合并变化；不改变协议和 JSON 格式，不引入后台线程或真实服务器。
## Decisions
RepoServerRole 增加显式延迟模式，MockServer 启用，直接磁盘仓库保留用于检查与迁移。首次访问加载角色与墓碑，此后读取内存；按角色记录 role/bag 待写位，单领域只访问对应文件，落地时比较内容，恢复原值则不写。成功领域清除待写状态，失败角色保留并继续其他角色。
MockServer 在 Tick 结束检测，包括无当前角色时；间隔由构造绑定 Env 的只读入口读取，调整后重新计时，默认 5 秒，0 禁用。正常传输释放显式 Flush，切换会话保留缓存。失败抛至现有 Net.Error；下一周期重试。
Env 使用共享键更新方法保留其他 .env 内容。GM 数字输入以 5 为步长并禁止非整倍数，经 Env 校验后保存，失败恢复显示。
## Risks / Trade-offs
异常退出可能丢失尚未落地数据；正常关闭补写。文件 IO 仍同步执行，但仅发生于检测节点及关闭；不做异步并发写入。
