# Design

## Context

角色窗口最小宽度写死为 430，装备槽 40、背包槽 48，背包图标内容区为 46。共享预览的旋转按钮 40，图标为圆形箭头。普通窗口标题 20，图鉴 24，背包使用默认 16。

## Goals / Non-Goals

将尺寸与标题来源统一，保持所有既有装备交互、角色预览比例、选角头像与小窗口滚动。只调整现有界面，不新增装备规则或存档字段。

## Decisions

- 提取 ItemSlotStyle 共享 48 外框、46 内容区及同一图标构建逻辑，装备不创建数量标签，避免两套尺寸再次漂移。
- 左侧五槽、右侧四槽，中间使用预览加双手横排；预览占上四行，双手与第五行鞋子对齐。统一行距并由相同格子尺寸计算高度，避免绝对坐标补丁。
- 移除角色窗口宽度下限，按内容计算宽度；预览中列固定紧凑宽度，使用现有滚动和标题拖动。
- 旋转按钮改为 28，图标 18，明确设置 IconAlignment 居中。SVG 使用向上翘起的开口弧形，保留所有预览页的八方向行为。
- PopupPanelStyle 统一创建 16 字号标题，背包、普通面板与图鉴复用；原生确认对话框保持引擎原有标题行为。

## Risks / Trade-offs

- 容器自然尺寸可能拉伸槽位或导致底行错位 → 运行时比较格子及图标实际矩形、鞋子与双手边缘，正常与小视口场景均检查。
- 共用图标及标题可能影响其他页面 → 运行角色管理、界面边界、图鉴和完整检查，核对图形截图。
