# Design

## Context

镜头默认缩放为 1.4，Debug 面板和雷达在同一个 CanvasLayer。空格的地块命令目前位于 `_unhandled_key_input`，因此已聚焦的 GUI 控件可先消费它。

## Goals / Non-Goals

**Goals:** 视野调节只影响镜头展示；空格处理优先于 Debug 控件的键盘激活。

**Non-Goals:** 不改区块加载配置、不持久化调试缩放、不改地图窗口缩放。

## Decisions

- HSlider 使用 1.0 至 4.0 的视野高度倍数，步长 0.25；主场景按 `默认 zoom / 倍数` 设置两个缩放轴。这样默认状态精确保留，滑条数值含义不受窗口像素尺寸影响。
- 空格在 `_input` 中处理并标记事件已处理，保留 M 和 F3 原有流程。处理限定在游玩且完整地图关闭时；文本输入控件聚焦时跳过，避免未来聊天输入冲突。
- 调整 Debug 面板与雷达布局，滑条不会遮住雷达。

## Risks / Trade-offs

- 视野扩大后画面边缘出现空白是当前调试需求；活跃区块数仍按配置决定。
- 大视野不增加地块加载量，画面可显示未加载范围。
