## Context

SettingService 已独占角色 JSON。普通弹窗与背包每帧重新居中，需改为优先恢复窗口位置。HUD 调整保持原有草稿契约。

## Goals / Non-Goals

实现三个窗口拖动、角色设置分类和快捷键自定义，不改变物品交互、服务器协议或 HUD 草稿保存行为。

## Decisions

- 增加独立 WindowPositions 字典，按视口比例保存；缺失坐标使用现有初始位置。独立于 HudPositions，避免恢复 HUD 默认时重置普通窗口。
- 可复用的标题栏拖动节点负责输入与边界，位置由设置服务读取，松开或失焦提交。普通弹窗和背包在排版后调用它应用位置，避免每帧居中。
- 快捷键采用逻辑键与 Ctrl/Alt/Shift 标志的不可变数值绑定，允许 A–Z、0–9、F1–F12；禁止 Meta、Alt+Tab/Alt+F4、Ctrl+Alt+Delete 及重复绑定。保留 Esc、回车、空格、方向键等操作键。
- 捕获阶段在 _Input 消费所有键盘事件，包括非法、释放及重复事件；成功保存退出高亮，关闭角色设置或切换页签取消捕获。正常快捷键在 _UnhandledKeyInput 处理并跳过文本输入、模态窗口和 HUD 调整。
- 窗口保持原有“背包”“大地图”节点名以兼容引用，快捷键标签按需求使用“道具”“地图”。

## Risks / Trade-offs

- 分辨率缩小可能裁剪保存位置 → 按当前面板尺寸裁剪，不把临时裁剪覆盖原设置。
- 旧文件或无效绑定 → 缺失值回填默认，冲突或非法绑定回退整组默认，避免重复操作。
- 保存失败 → 捕获保持高亮并提示，成功写盘后才替换生效绑定。

## Migration Plan

新增 JSON 字段采用默认值，既有 HUD 数据保持兼容；回滚提交可恢复原界面。
