# Design

## Context

见 proposal.md。现有 ActorView 的 Facing 容器统一镜像身体和头部，身体 AnimatedSprite2D 是唯一时钟。外部 raw/avatar/weaponr 保留五方向 DIMG 完整帧和 Weaponr.ini 遮挡指令；现有图鉴仅保存首帧。身体像素块尾还保留左右手连接点。

## Goals / Non-Goals

**Goals:** 独立武器资源按身体动作和手部连接点组合，支持男女八方向与动作复用，不复制身体图集。

**Non-Goals:** 不引入装备槽、服务端装备、背包穿戴、战斗或属性规则。

## Decisions

- 使用测试长剑对应的基础右手剑系列，导入男女实际存在的动作；缺省动作显式指定复用关系，并将身体帧映射到武器帧，记录来源及哈希。
- 身体新增右手挂接坐标，武器资源保存每帧剑柄连接坐标和前后层数据；位置为身体挂接点减身体世界锚点减武器连接点，复用头部组合契约。避免凭肉眼固定偏移。
- 武器使用 Sprite2D，共享 Facing 镜像并由身体 FrameChanged 同步，避免第二动画时钟漂移。逐帧遮挡取自原始 Weaponr.ini 的 50 槽逐帧层级表；在角色内部调整节点顺序，不增加跨实体 Z 值。
- AnimationService 缓存武器资源；默认外观保留在表现层，兼容现有协议、缓存、ECS 和存档。

## Risks / Trade-offs

- 原始动作有复用与空帧 → 导入时检查计数和映射，回归覆盖全部动作，图形预览检查站立和跑步握点。
- 镜像或改向可能错层/漂移 → 共用镜像容器、身体时钟，并验收八方向与逐帧定位。
- 这是默认外观 → 后续实际装备系统另行确认。
