# Design

## Context

见proposal.md。当前射线遇到任意非零alpha就停止，连接层随后又清除原画所有非零alpha处的像素。第6帧护手接缝含17、51、119等低alpha像素，内部细缝仍然透底。现有GPU验收仅比较背景色是否完全一致，漏判这类像素。

## Goals / Non-Goals

目标：恢复握柄内部连续不透明的轮廓，深浅背景下接缝不变色；保持原始武器纹理、手掌遮挡和外缘抗锯齿。

## Decisions

- 保持四像素柄芯，射线延伸至完全不透明的护手像素，避免接在抗锯齿边缘。对握点八像素范围的轮廓做九像素核闭合，恢复原手形切口而非只画窄线。补充层只清除与原画实心像素的重叠，允许在该局部范围衬住半透明切口；不改原始纹理，不把整张剑的抗锯齿边缘变成实心。
- 原图黄金仍验证全部源像素不变；补充层检查改为不重叠实心源像素，透明度不足的源切口允许下衬。
- 针对截图第6帧用独立矩形内部接缝区域校验组合alpha为1，并以真实GPU深浅背景逐像素对比整段，替代只检查几个非背景点。
- 复查男女剑类近景及完整审查输出，仅剑类跨手视图可变化。

## Risks / Trade-offs

- 下衬扩大外轮廓 → 仅已有受限柄芯可下衬，保留实心像素和原纹理，通过放大近景审查。
- 自动测试仍漏审 → 检查完整内部接缝区域和双背景图，而不是稀疏探针，保留原始及腿部遮挡回归。

## Migration Plan

重导握柄资源后运行项目与GPU验收，重新导出原路径网页和ZIP，备份上一版并保留可回滚本地提交。
