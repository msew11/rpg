# Spec Delta

## MODIFIED Requirements

### Requirement: 客户端原子同步与预测
客户端 SHALL 完整验证世界帧后原子更新自身、地图与远端角色。点击立即预测且发包最多 20Hz；确认后保留较新意图。远端 SHALL 使用 100ms 插值，最多外推 100ms 且不越过目标；停止或外推到达目标时 SHALL 保留最近有效移动朝向，持续静止不重置朝向，各角色独立保存并随离开视野或世界清理。首次静止可见且无移动信息时沿用默认朝向。缺口暂停增量并保持一个重同步请求；物品及 GM 写仍禁用。
#### Scenario: 缺口和非法批次
- **WHEN** 收到缺口、重复帧或非法角色及地图状态
- **THEN** 重复忽略，缺口请求全量恢复，非法批次不部分提交

#### Scenario: 远程角色停止保持方向
- **WHEN** 远程角色沿任一八方向移动或中途转向后停止，或客户端外推到达目标
- **THEN** 站立保持最近有效移动方向，后续静止更新不改变该方向，即使两次呈现间已接收移动与停止样本也保持一致

#### Scenario: 远程朝向隔离与清理
- **WHEN** 多个远程角色分别停止，随后离开视野重新进入或清理世界后重新进入
- **THEN** 各角色保留各自最近朝向，移除后不继承旧可见周期的朝向，首次静止可见沿用默认值
