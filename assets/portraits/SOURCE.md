# 角色 HUD 头像来源

`DThed*.png` 来自用户提供的 `art_export/png/res/head/`。`head_portrait_map.html` 按原始名称确认 `head1101` 对应 `DThed011_01`，依次到 `head8801` 对应 `DThed088_01`；`_01` 为男、`_51` 为女。八组每组八款，对应项目 `head_composition.json` 中每种性别的头型编号 9–72。`XThed` 是同组的小头像版本。

编号 1–8 对应 `head0*`，73–74 对应 `head89*`、`head91*`，参考页没有对应的 DT/XT 头像，因此不在创角可选范围。旧角色仍可显示，HUD 与选角预览回退使用 `assets/characters/heads/` 的正面帧。运行只依赖项目内资源。
