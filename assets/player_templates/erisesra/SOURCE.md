# ErisEsra Character Templates Pack

- 作者：Eris Esra
- 来源：https://erisesra.itch.io/character-templates-pack
- 使用版本：Character Template 4.1（2026-09-03 上传）
- 本项目使用文件：16×16 与 16×32 的七种独立 PNG 精灵表。
- 角色绘制尺寸分别为 16×16 与 16×32；精灵表帧尺寸分别为 24×24 与 32×32。

| 动作 | 16×16 图尺寸 | 16×32 图尺寸 | 当前游戏状态 |
| --- | --- | --- | --- |
| 待机 `idle.png` | 96×120，4 列×5 行 | 128×160，4 列×5 行 | 已播放 |
| 行走 `walk.png` | 96×120，4 列×5 行 | 128×160，4 列×5 行 | 已播放 |
| 跑步 `run.png` | 144×120，6 列×5 行 | 192×160，6 列×5 行 | 资源待接入 |
| 攻击 `attack.png` | 144×120，6 列×5 行 | 224×160，7 列×5 行 | 资源待接入 |
| 交互 `interact.png` | 96×120，4 列×5 行 | 128×160，4 列×5 行 | 资源待接入 |
| 跳跃 `jump.png` | 120×110，5 列×5 行 | 160×160，5 列×5 行 | 资源待接入；16×16 每行高 22 像素 |
| 转身 `rotate.png` | 192×24，8 列×1 行 | 256×32，8 列×1 行 | 资源待接入 |

素材包未提供受击、死亡的独立动作图。当前游戏只自动播放待机和行走；其他动作仍需对应的玩法触发与播放规则。

作者允许在免费及商业游戏中使用这些模板，禁止将模板或修改版作为素材包转售或再分发。免费产品须注明作者并链接原始素材页。此文件保留来源和署名；游戏正式发布时也应在游戏可见位置提供署名与链接。
